# 统一交易控制中心 — Data Compatibility & Verification Spec

- 状态：APPROVED / FROZEN
- 版本：1.3
- 日期：2026-09-10
- 修订：用户于 2026-09-10 授权偏见/方向/结构/机会矩阵与兼容边界收紧。验证应覆盖新字段顺序、ARIA、提示、持仓冲突、当前统一 JSON 中的内部 `unjudged`，以及旧独立日内状态卡备份的明确零副作用拒绝。

## 1. 目标

证明冻结的新状态卡规则正确实施、不丢失既有状态卡或账户风险数据，并且任何损坏、歧义、并发或存储失败都不会静默覆盖当前数据。

## 2. 基线

- 合并后的回归门槛：全量测试必须全部通过，并在验证报告中记录实际数量。
- 私密真实备份的历史审计结论不作为旧独立日内文件可导入的授权；当前统一 JSON 与风险 schema 1/2 兼容路径分别验证。
- 真实备份只在本地读取，不复制到仓库；仓库内只能使用脱敏合成夹具。

## 3. 测试分层

### 3.1 纯函数测试

- 格式分类；
- 顶层与当前 section 校验；
- 完整验证；
- 局部替换保持性；
- 序列化往返；
- 错误路径和字段定位；
- 重复导入幂等性。

### 3.2 存储适配器测试

- 首次旧风险键兼容恢复；
- canonical key 优先；
- pre-import 快照；
- 写入后回读；
- 配额/异常；
- 多标签页 revision 冲突。

### 3.3 DOM / 浏览器测试

- 导入预览与确认；
- 首页/风险视图切换；
- 刷新、返回、前进；
- 导入后选中账户和卡片选项显示；
- 三种主题；
- 桌面与窄屏；
- `file://` 降级。
- 偏见 × 方向的全部九种组合，以及方向 × 结构 × 机会的全部十八种组合；
- `unjudged` 在当前统一 JSON 中不可见但可安全保留；未入场确认失效、持仓冲突警示与平仓后的方向重选。

### 3.4 公开发布测试

- 实际 Pages commit 和静态资源；
- `#/home`、`#/risk` 硬刷新；
- 同-origin 旧风险键兼容恢复；
- 旧 URL 只读跳转；
- 缓存更新与版本标识。

## 5. 保持性断言

### 5.1 旧状态卡导入拒绝

导入前后必须满足：

```text
after === before
afterStorageRaw === beforeStorageRaw
```

比较采用深度结构相等与原始存储字符串相等，不只比较账户数量或界面文字；同时校验可见 DOM 未变。

### 5.2 旧风险导入

导入前后必须满足：

```text
after.sections.intraday === before.sections.intraday
after.preferences === before.preferences
```

### 5.3 完整导入

- 两个 section 与导入文件的当前规范化结果深度相等；
- 顶层 revision 可按导入规则重新生成，不要求与文件相等；
- savedAt 可更新为导入提交时间；
- 除上述明确规范化字段外不得改变业务内容。

## 6. 四方一致性

每次启动、导入和关键恢复后都要对照：

1. 备份 payload；
2. 校验/兼容恢复后的内存 state；
3. canonical localStorage；
4. DOM 中的当前选择、状态、账户和风险结果。

四方任一不一致即不通过，不得仅凭单元测试或页面能打开验收。

## 7. Golden fixtures

仓库内需要生成以下脱敏夹具：

- 当前 unified v1：空白、完整活动状态、多账户长历史和内部 `unjudged`；
- intraday v1/v2/v3：仅作为明确拒绝输入；
- risk v1/v2：空账户、单账户、多账户、活动事件、旧快照、previousSession；
- unified v1：空白、完整活动状态、多账户长历史；
- invalid：损坏 JSON、未来版本、重复 ID、断裂事件链、歧义格式、超限文件描述。

每个夹具必须有预期处理结果、受影响 section、业务摘要和内容哈希。夹具不得包含真实账户信息。

## 8. 验收报告要求

实现任务的 Verification 报告必须列出：

- 实际测试命令、时间和通过数量；
- 两个旧回归套件的结果；
- 新兼容矩阵逐项结果；
- 真实备份只读验证摘要，不含余额和账户名；
- 本地预览 URL、浏览器和截图；
- 公开 Pages commit、URL、缓存验证和旧站点行为；
- 已知问题、回退 commit 和是否允许发布。

## 9. Release blocker

以下任一情况存在时禁止公开发布：

- 当前统一备份或旧风险备份无法导入或出现数据漂移；
- 分项导入改变了另一 section；
- 重复 ID 或断裂余额链仍可通过；
- 写入失败会导致旧数据被空白覆盖；
- 状态卡或风险核心回归失败；
- 本地通过但公开 Pages 未验证；
- 旧独立状态卡备份可被导入、读取或导致任何状态变化。
